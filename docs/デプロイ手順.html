当番Bot デプロイ手順

Google Apps Script と LINE 公式アカウントを無料で用意し、Bot を動かすまで。所要 30 分ほど。必要なのは Google アカウントと LINE アカウントだけ。

1LINE2シート3GAS4公開5Webhook6トリガー7グループ8確認

あらかじめ控えるもの

途中で 4 つの値が出てきます。メモ帳に貼っておくと楽です。

  • チャネルアクセストークン（手順 1）
  • 管理者のユーザーID（手順 1）
  • スプレッドシート ID（手順 2）
  • ウェブアプリ URL（手順 4）

1LINE 公式アカウントを作る

LINE Developers で Messaging API チャネルを作る

  1. https://developers.line.biz/console/ に LINE アカウントでログイン
  2. 「プロバイダー」を作る（名前は何でもよい）
  3. 「Messaging API チャネル」を作る
    • チャネル名：表示される Bot の名前（例：当番Bot）
    • 業種：任意
  4. 作ったチャネルの Messaging API 設定 タブで
    • 「チャネルアクセストークン（長期）」を 発行 → チャネルアクセストークン として控える
    • 「応答メッセージ」を オフ、「あいさつメッセージ」を オフ（LINE Official Account Manager に飛びます）
    • 「Webhook の利用」は、手順 5 でオンにする
  5. チャネル基本設定 タブの一番下「あなたのユーザーID」を 管理者のユーザーID として控える（U で始まる 33 文字）
料金プランは「コミュニケーションプラン」（無料、月 200 通）のままでよい。

2スプレッドシートを用意する

空のシートを 1 つ作るだけ

  1. Google スプレッドシートを新規作成（名前は何でもよい）
  2. URL の /d/ と /edit の間の文字列を スプレッドシート ID として控える 
    https://docs.google.com/spreadsheets/d/ここが ID/edit

タブは Bot が自動で作るので、何もしなくてよい。

3GAS を用意する

コードを貼って、初回セットアップを 1 回動かす

  1. https://script.google.com/ で「新しいプロジェクト」
  2. プロジェクト名を付ける（例：当番Bot）
  3. このリポジトリの src/ にあるファイルをすべて貼り付ける
    • ファイル名はリポジトリと同じにする
    • appsscript.json は プロジェクトの設定 → 「appsscript.json をエディタで表示」をオンにして貼る
  4. src/00_config.gs の先頭にある 2 つの値を書き換える 
    var SPREADSHEET_ID = '（スプレッドシート ID）';
var CHANNEL_ACCESS_TOKEN = '（チャネルアクセストークン）';
  5. エディタ上部の関数選択で setup を選び 実行
    • 初回は権限の許可を求められるので許可する
    • スプレッドシートに 5 つのタブ（設定／名簿／状態／回答ログ／当番_YYYY年度）ができる
  6. スプレッドシートの 設定 タブを開き、管理者ID に 管理者のユーザーID を貼る

4ウェブアプリとして公開する

LINE から呼べる URL を作る

  1. GAS エディタ右上 デプロイ → 「新しいデプロイ」
  2. 種類：ウェブアプリ
    • 実行ユーザー：自分
    • アクセスできるユーザー：全員
  3. 「デプロイ」→ 出てきた URL を ウェブアプリ URL として控える 
    https://script.google.com/macros/s/xxxxxxxx/exec
コードを直したときは デプロイを管理 → 鉛筆 → バージョン「新バージョン」→ デプロイ。URL は変わりません。
設定 シートの値を変えるだけなら再デプロイは不要です。

5Webhook をつなぐ

LINE に GAS の URL を教える

  1. LINE Developers のチャネル → Messaging API 設定
  2. Webhook URL に ウェブアプリ URL を貼って「更新」
  3. 「検証」を押して「成功」を確認
  4. 「Webhook の利用」を オン

6定時トリガーを設定する

毎朝 9 時台に 1 回動かす

  1. GAS エディタ左の時計アイコン トリガー → 「トリガーを追加」
  2. 実行する関数：daily
    イベントのソース：時間主導型
    時間ベースのトリガー：日付ベースのタイマー
    時刻：午前 9〜10 時
  3. 保存

15 日なら「始めますか」、25 日なら未回答一覧を管理者に送ります。それ以外の日は何もしません。

7グループに入れる

Bot を招待して、全員に友だち追加してもらう

  1. LINE で Bot を友だち追加（QR コードは Messaging API 設定タブにある）
  2. 当番を決めるグループに Bot を招待 → Bot が「友だち追加してください」と送る。設定 の グループID が自動で入る
  3. 全員に友だち追加してもらう
Bot はグループに入る前からいた人を見つけられません。 全員の友だち追加が済むまで、その人には当番の相談が届きません。詳しくは運用マニュアル 1-1。

8動作確認

  1. 管理者の 1 対 1 トークで Bot を開き、メニューの 状況 を押す → 「いま進めているものはありません。」と返れば OK
  2. 開始 → 部制 → 日数 → この日程でOK まで試し、メンバーにカレンダーが届くことを確認
  3. 確認が終わったら 中止

うまくいかないとき

症状見るところ
Webhook の「検証」が失敗する手順 4 の「アクセスできるユーザー」が「全員」か。デプロイし直したか
ボタンを押しても返事がないGAS エディタ左「実行数」でエラーを見る。トークンが正しいか
「始めますか」が来ないトリガーが daily で毎日になっているか。設定 の管理者ID が正しいか
グループID が入らないBot をグループから外して、もう一度招待する
管理者ID がわからないLINE Developers → チャネル基本設定 → 一番下「あなたのユーザーID」

更新のしかた

  1. GAS にコードを貼り直す
  2. デプロイを管理 → 鉛筆 → 「新バージョン」→ デプロイ

シートのデータはそのまま残ります。
